# 第三方许可与署名

本包是 Kotana Runtime 中桌宠集成层的独立抽取版。**代码许可与它对接的外部程序许可是分开的。**

## 1. 本包自身

- 自有代码采用 **MIT**，全文见 [LICENSE](LICENSE)。
- 本包**不包含** dsh-pet 程序本体、启动器、动画、立绘或任何美术素材，也不包含内置桌宠页面。

## 2. dsh-pet（可选的外部桌宠程序）

- 项目地址：<https://github.com/PC2005-cloud/dsh-pet>
- 代码许可：**MIT**
- 素材（动画 / 提示词 / 源视频）：允许开源使用，具体授权跟随角色原型的形象授权。
- 二创约定：基于该项目的衍生 / 改版 / 换皮作品，在 GitHub 仓库、产品官网等公开渠道上
  **必须附上原作者 GitHub 地址**：<https://github.com/PC2005-cloud/dsh-pet>。
- 与本包的关系：本包只通过 dsh-pet 自己的本地接口和 CDP 调试端口与它交互，
  不链接、不修改其代码；如需分发 dsh-pet 本体，须自行遵守其许可与上述署名要求。

## 3. 内置桌宠形象

- Kotana 的内置桌宠页面与「大肥鱼」形象不在本包内。
- 若在其他地方使用该形象，仍受其原有许可约束（CC BY-NC-SA 4.0，禁止商业化）。
